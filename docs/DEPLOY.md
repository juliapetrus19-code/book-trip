# BookTrip — как запустить сайт (инструкция для владельца)

Эта инструкция написана для человека без технического опыта. Вам понадобятся: аккаунт GitHub
(там уже лежит код сайта), банковская карта и примерно 30 минут.

Сайт работает в двух режимах:

| Режим | Что нужно | Что умеет |
|---|---|---|
| **Демо** | ничего | Только книги, которые встроены в сайт. Бесплатно. |
| **Живой режим** | ключ Anthropic (Claude) | Любая книга: пересказ, термины, персонажи, похожие книги, 3D-фильм. |
| **Портреты** | + ключ Google Gemini | AI-портрет любого персонажа. |
| **Видео (премиум)** | + ключ Gemini + секретный код `PREMIUM_CODE` | Настоящее AI-видео: 3 ролика по 8 секунд. |

Можно начать с демо, а ключи добавить позже — сайт сам поймёт, что они появились.

---

## 1. Ключ Anthropic (Claude) — для живого режима

1. Откройте **https://console.anthropic.com** и зарегистрируйтесь (можно через Google).
2. Пополните баланс: **Settings → Billing → Add credits** (Настройки → Оплата → Пополнить).
   Для начала достаточно $10–20. Ключ не работает, пока на балансе $0.
3. Поставьте лимит расходов, чтобы не было сюрпризов: **Settings → Limits** — например, $50 в месяц.
4. Создайте ключ: **API Keys → Create Key**. Назовите его, например, `booktrip`.
5. Скопируйте ключ (начинается с `sk-ant-…`) и сохраните в надёжном месте.
   **Ключ показывается только один раз.** Никому его не отправляйте и не публикуйте.

## 2. Ключ Google Gemini — для портретов и видео (по желанию)

1. Откройте **https://aistudio.google.com** и войдите с Google-аккаунтом.
2. Нажмите **Get API key → Create API key** (Получить ключ → Создать ключ).
3. Включите оплату: рядом с ключом нажмите **Set up billing** (Настроить оплату) и привяжите карту
   в Google Cloud. Без оплаты генерация картинок и видео не работает.
4. Рекомендуем в Google Cloud настроить бюджет с уведомлениями: **Billing → Budgets & alerts**.
5. Скопируйте ключ (начинается с `AIza…`) и сохраните его.

## 3. Секретные значения, которые вы придумываете сами

- **`SIGNING_SECRET`** — длинная случайная строка (40+ символов), которой сайт подписывает ссылки на
  портреты и видео, чтобы никто не мог пользоваться вашими ключами бесплатно. Сгенерируйте её
  любым генератором паролей (например, в вашем менеджере паролей). Посетителям её знать не нужно.
- **`PREMIUM_CODE`** — код доступа к AI-видео. Его вы выдаёте платным клиентам; они вводят его на
  сайте. Чтобы закрыть доступ всем старым клиентам — просто смените код. Если оставить пустым,
  видео полностью выключено (кнопка будет недоступна).

## 4. Публикация на Vercel

1. Откройте **https://vercel.com** и войдите через GitHub (**Continue with GitHub**).
2. Нажмите **Add New… → Project**, найдите репозиторий сайта и нажмите **Import**.
3. На экране настройки:
   - **Framework Preset**: `Other`;
   - **Build Command** и **Output Directory** оставьте пустыми — сборка не нужна.
4. Откройте раздел **Environment Variables** (переменные окружения) и добавьте по одной:

   | Name (имя) | Value (значение) | Обязательно? |
   |---|---|---|
   | `ANTHROPIC_API_KEY` | ваш ключ `sk-ant-…` | для живого режима |
   | `GEMINI_API_KEY` | ваш ключ `AIza…` | для портретов и видео |
   | `SIGNING_SECRET` | ваша случайная строка | очень желательно |
   | `PREMIUM_CODE` | ваш код доступа к видео | для видео |
   | `ANTHROPIC_MODEL` | не заполнять (по умолчанию `claude-opus-5-5`) | нет |
   | `BOOK_EFFORT` | не заполнять (`medium`); `high` — тщательнее, но дороже | нет |
   | `GEMINI_IMAGE_MODEL`, `GEMINI_VIDEO_MODEL` | не заполнять | нет |

5. Нажмите **Deploy** и подождите 1–2 минуты. Vercel покажет адрес сайта вида
   `https://booktrip-xxxx.vercel.app`.
6. Проверьте: откройте `https://ваш-сайт/api/health`. Должно быть что-то вроде
   `{"live":true,"portraits":true,"video":true,…}`. Ключи там никогда не показываются.

### Если ключи добавлены или изменены позже

Переменные применяются только к новым публикациям. После изменения откройте
**Deployments**, у последней публикации нажмите **⋯ → Redeploy**.

### Свой домен

**Project → Settings → Domains → Add** и следуйте подсказкам Vercel.

## 5. Сколько это стоит (примерно)

| Что | Цена |
|---|---|
| Claude Opus 5.5 | $4 за 1 млн входящих токенов и $20 за 1 млн исходящих |
| Одна новая книга целиком (поиск + пересказ + персонажи + фильм) | ≈ $0.15–0.35 **один раз** |
| Повторные открытия той же книги на том же языке | бесплатно: ответ кэшируется сетью Vercel для всех посетителей |
| Один AI-портрет персонажа | ≈ $0.04 (тоже кэшируется) |
| AI-видео (Veo 3.1 Fast, ≈ $0.10–0.12 за секунду) | 3 ролика × 8 с ≈ **$2.5–3** за одно видео |
| Хостинг Vercel | бесплатный тариф Hobby для старта; для коммерческого сайта нужен Pro |

Каждый язык (русский, украинский, английский) — отдельный ответ, поэтому одна книга на трёх языках
стоит примерно втрое дороже, но тоже только один раз. После нового деплоя кэш Vercel может начаться
заново — первые открытия популярных книг снова будут платными.

Видео — самая дорогая часть, поэтому оно доступно только с `PREMIUM_CODE`. Установите цену для
клиентов с запасом (например, от $5 за видео).

## 6. Защита от злоупотреблений (обязательно прочитайте)

Сайт уже ограничивает частоту запросов с одного адреса (≈30 книжных запросов и 10 портретов за
10 минут, 3 видео в час) и принимает на портреты и видео только подписанные сайтом описания. Но эти
счётчики живут в памяти серверов и сбрасываются, поэтому настройте ещё и защиту Vercel:

1. В проекте откройте **Firewall → Configure → New Rule** (Брандмауэр → Новое правило).
2. Правило «API»: **If** `Request Path` **starts with** `/api/` → **Then** `Rate Limit`,
   например 60 запросов за 60 секунд с одного IP; действие при превышении —
   `Too Many Requests (429)`.
3. Правило «Видео»: путь `/api/video` → 10 запросов за 10 минут.
4. Правило «Портреты»: путь `/api/portrait` → 20 запросов за 10 минут.
5. Нажмите **Save** и **Publish**.
6. Если видите всплеск подозрительного трафика — включите **Attack Challenge Mode** в том же разделе.

Также обязательно:

- лимит расходов в Anthropic (**Settings → Limits**) и бюджет в Google Cloud;
- в Vercel — **Settings → Billing → Spend Management**, чтобы хостинг не вышел за ваш бюджет;
- никогда не пишите ключи в код, в чаты и в письма — только в Environment Variables на Vercel.
  Если ключ утёк: удалите его в консоли Anthropic/Google, создайте новый, замените в Vercel и
  сделайте Redeploy.

## 7. Если что-то не работает

| Что видно | Что делать |
|---|---|
| `/api/health` показывает `"live": false` | Нет `ANTHROPIC_API_KEY` или не сделан Redeploy после добавления. |
| Сайт пишет, что живой режим не настроен, хотя ключ есть | Ключ неверный или закончились деньги на балансе Anthropic. |
| «Слишком много запросов» | Сработало ограничение частоты — подождите 10 минут. |
| Портреты не появляются | Проверьте `GEMINI_API_KEY` и что в Google включена оплата. |
| Видео недоступно | Нужны и `GEMINI_API_KEY`, и `PREMIUM_CODE`; клиент должен ввести верный код. |
| Ошибки в работе | Vercel → проект → **Logs**: там видны сообщения сервера (без ключей). |

### Для разработчика: локальный запуск

```bash
npm install
ANTHROPIC_API_KEY=sk-ant-… GEMINI_API_KEY=AIza… PREMIUM_CODE=test node tests/dev-server.mjs 5600
# сайт: http://localhost:5600   тесты: node --test tests/*.test.mjs
```
